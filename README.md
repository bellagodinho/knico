# Skein

A free, local-first knitting and crochet notebook. Your data stays on your device.

## Run it (Windows)
1. Install Node.js LTS, Git, and VS Code.
2. In this folder: `npm install`, then `npm run dev`.

## Put it online (free) and install on iPhone
1. Create a public GitHub repo, then `git init`, commit, and push to `main`.
2. Repo Settings > Pages > Source: **GitHub Actions**. The workflow deploys on every push.
3. Open the Pages URL in iPhone Safari > Share > Add to Home Screen.
4. Open the app from the Home Screen icon, go to Diagnostics, and run each test.

Never commit API keys. Lessons live in `docs/lessons/`.
